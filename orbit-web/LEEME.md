# ORBIT · Node.js

Ejecuta el proyecto desde la raíz con `npm ci`, `npm run db:migrate` y `npm start`. Abre http://localhost:3000.

La web, Unity y la API se sirven desde Node.js. La configuración privada está en `.env` en la raíz, fuera de la carpeta pública. No requiere XAMPP ni PHP.

Consulta [la documentación completa](../README.md) para Gmail, acceso del administrador, seguridad, pruebas y despliegue.
